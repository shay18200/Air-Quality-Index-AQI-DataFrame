# Air-Quality-Index-AQI-DataFrame
A Python project using Pandas to organize and display Air Quality Index (AQI) levels and their health categories.

For this project, I used Python and Pandas to create a DataFrame showing different Air Quality Index (AQI) levels. I organized the information by color, health concern, and low and high AQI values for data visualization 

**What the project includes:**
Six AQI categories: Green, Yellow, Orange, Red, Purple, and Maroon
Health concerns for each category
Low and high AQI values
Displaying the first two and last two rows
Showing the number of rows and columns
Viewing DataFrame information

**#What I learned:**
Creating DataFrames using Pandas
Setting an index
Using head() and tail()
Using shape and len()
Using info() to review DataFrame information
